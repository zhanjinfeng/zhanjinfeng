## 👋 About

I'm Jeffrey, an AI developer and full-stack engineer focused on turning ambitious ideas into useful, live products.

My current interests sit at the intersection of:

- 🤖 Agent-native products and AI-assisted workflows
- 🧩 Model infrastructure, APIs, and developer platforms
- ☁️ Cloud-native systems that are reliable, secure, and easy to ship
- 🎨 Interfaces that make powerful technology feel simple

## 🧭 What I'm building

| Project | Description |
| --- | --- |
| [**Happycapy**](https://happycapy.ai/) | An agent-native computer where models, skills, and automations work together to get things done. |
